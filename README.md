# CodeAlpha_CGPACalculator

A C++ console application developed as **Task 1** for the **CodeAlpha C++ Programming Internship**.

## Features
- Calculate GPA/CGPA
- Input multiple courses
- Enter course names, grades, and credit hours
- Automatic grade point calculation
- Display total credits and final CGPA
- User-friendly console interface

## Technologies Used
- C++
- Structures
- Functions
- Loops
- Conditional Statements

## How to Run
1. Clone or download this repository.
2. Open the project in Visual Studio or any C++ IDE.
3. Compile and run the program.
4. Enter course details and view the calculated CGPA.
